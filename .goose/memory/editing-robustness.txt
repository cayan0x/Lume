# editing pitfalls windows gate workflow
【改这个仓库时省时间的坑（都是这两个会话实测踩出来的）】

1. **别用中文当 edit 锚点**：控制台读回来的中文是乱码版本，据此写的 `before` 永远匹配不上。做法：**只用 ASCII 锚点**（代码行、标识符、`from "./x.js";` 这类），或写一次性 node 脚本按「行号 + ASCII 片段校验」替换。脚本里每处替换都要**断言锚点恰好命中 1 次**，命中不上就打印并跳过——这才是"谨慎地改"。
2. **缩进是 tab**：`edit` 工具里用 4 空格写的锚点会失败；要么用 tab，要么只锚定不含缩进的内层文本（替换子串，保留原缩进）。
3. **脚本自身别写嵌套模板字面量**：我要生成的代码里含 `` `...${x}...` `` 时，脚本的模板字面量会解析失败（本会话踩了三次）。改成数组 + 单引号拼接，或把反引号转义。
4. **多行命令会被 cmd 截断**：只能用 `&` 串联，或写成脚本文件再跑（推荐）。
5. **`npx` / `npm exec` 在这台机器不可用**（Node 垫片坏）；脚本里一律 `process.execPath` 直接跑 node。
6. **`execFileSync("npm.cmd", args, {shell:true})` 会静默空跑**（退出码 0、无输出、什么都没做）→ npm 发布直接走 shell。
7. **发布门禁 `scripts/release-check.mjs` 的本地采集有文件白名单**：新增分文件断言时必须把该文件加进那个清单，否则检查读到空字符串而"假红"（本会话踩了两次）。
8. **改 ProjectStore 的域/构造参数后**：`src/index.ts` 的 `new ProjectStore({...})` 与 `test/project-store.test.ts` 的 fake tables 都要同步补表，否则 tsc/测试立刻红（这是好事：说明类型在兜底）。
9. 大改后固定验证顺序：`tsc` → `npm test` → `npm run build` → `node scripts/release-check.mjs` → `node scripts/install-local.mjs`（装本机）。

# lume harness-vs-real event-shape arguments-string silent-dead-code pending-restart
【假宿主与真机的入参形状不一致 → 一批功能静默失效（2026-09-23 现场）】真机 DSH 的 tool/call 事件 data 形状是 { turn, step, callId, name, arguments }，其中 **arguments 是 JSON 字符串**（不是对象）；而 test/apply-harness.ts 发的是 { args: {...对象} }。因此只认 object 的 helper（toolArgsFromEvent / targetPathFromToolEvent）在真机上 path 永远为 null，导致**依赖工具入参的功能全部静默失效**：①自动改动台账 ②引用核对（读窗口索引）③首改前定位门槛 ④auto-verify（按 target 推进 verified）⑤交付对账（台账空→永不触发）⑥需求覆盖核对（抓不到产物正文）。证据：lume_project.json 里该会话 ledger=undefined；harness.log 里 verify-as-you-go（steps=7，inspect=0，mutate=4）——读了文件却 inspect 为 0。修法：toolArgsFromEvent 支持字符串入参（JSON.parse），targetPathFromToolEvent 复用它；回归测试必须用**真机形状**（arguments: JSON.stringify({file_path,new_string})）。**通用教训：单测跑在假宿主上，凡是「只用工具名/文本」的功能不受影响，凡依赖「工具入参」的功能都可能被形状差异打死——这类改动必须拿真机事件样本做回归。** 修复已装本机（live 逐字节相同），待重启生效。

# codemod quoting crlf template-literal storage-table-naming
【这批反复踩到的三个坑（都是机械改代码时的）】① **别在生成的代码里用双引号**：我用 Node 脚本写 TypeScript 时，中文注释里的英文双引号会把脚本字符串提前闭合（SyntaxError），一晚上踩了三次；注释里用「」或单引号。② **别用模板字面量包被生成的代码**：`${}` 会插值、反引号会断串。③ **CRLF**：本仓多数文件是 CRLF，Node 脚本里的锚点字符串必须用 \r\n，否则普遍 MISS（project.ts 用 tab+CRLF、session-deps.ts 用 tab+LF，逐文件确认）。另外：DSH 存储域强制表名 /^[a-z][a-z0-9_]*$/（camelCase 表名会让所有相关测试文件加载失败）。
