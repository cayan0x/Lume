# Lume · 微光

**DSH Desktop 的增强插件。两块能力：任务执行纪律，和一段能延续的关系。**

装在人设、记忆与任务协议三个位置，约束**按需注入**——闲聊轮不额外花 token。

## 一、任务执行纪律

**问题**：长任务里模型丢的通常不是"不知道要量化"，而是**没有一个地方放量化结果**；而它最危险的失效是"看着跑完了，其实没验证"。

### 载具：把量化与台账变成可检查的产出

| 载具 | 内容 |
|---|---|
| **任务契约** | 目标 / 范围 / 数量（**先估后回填实际**）/ 完成判据 / 非目标 / 待确认（≤2，默认 0） |
| **改动台账** | 每处改动：改了什么、为什么、**怎么验证的**；未验证的条目会在交付时被点出来 |
| **假设台账** | 含**已排除项**——被验证推翻的假设也留档，避免重撞 |
| **项目知识** | 按**工作目录**跨会话累积：构建方式、测试命令、约定、死路；带编号可点名删除 |

项目知识**不需要你提醒**：插件从工具结果、助手结论、你的规范陈述三处机械识别；新会话开局直接带上（同工作目录，其它需求的知识不会串味）。

### 触发器：按轨迹纠偏（不是按你的话）

撒网不收敛、连写不验、死路重撞、需求漂移、只读核对里反复试探——命中就给**验证降级阶梯**或收敛提醒。最近新增的是**证据类**：

- **引用核对**：写了 `文件:行`，但这一段你这次没打开过 → 点出来；
- **断言核对**：对没见过的符号下"不存在/没映射"这类否定断言 → 要求给出处；
- **需求覆盖核对**：把需求原句与交付物里的句子**并列**，并把引用不到的章节号点出来；
- **提问核对**：把"我没查/我猜"包装成"待你定" → 要求先核实前提。

### 长会话不再等于记忆丢失

- **上下文压力预警**：占用到 75% / 90% 时提醒收尾并开新会话（**会话记忆已保存**）；
- **会话记忆**：每轮把结构化状态（目标/已拍板/未决/关键定位/改动与验证状态）导出；新会话开局注入"上次会话记忆"，你说一句"继续"就能接上；
- **历史补蒸馏**：启动时扫最近 7 天的会话（**包括已经撑满、聊不动的那些**）补出跨会话知识，幂等不重复。

### 分层注入与成本

系统提示词只放**会话恒定**内容（人设段、协议），易变内容（路由、台账、锚点、提醒）随**对话尾部快照**下发——**前缀缓存每步可用**。实测：稳态缓存命中约 99%；只在重启且插件构建变化时才付一次冷启动成本（约 19 万 tokens），所以协议正文的改动会被攒批。

## 二、人设系统

**人设即人**：换人设 = 换关系，不只是换语气。

- **内建人设**：傲娇 / 前辈 / 管家 / 冷淡 等，也可蒸馏你自己的；
- **人设蒸馏**：从**聊天记录、小说、剧本、人物设定文档**里提炼具名角色——语气、口头禅、回复篇幅都**锚定真实素材的统计**，而不是凭想象编；
- **长期记忆与临时记忆**：以人设为主键**跨会话、跨项目**持久；有时间界限的事实自动过期；
- **风格收敛**：你的纠正会自动转成风格约定；你认可的回复摘录为语料；双向反馈随使用收敛；
- **记忆星图**：把记忆与关联可视化，可筛选、可编辑、可删除；
- **角色卡导出/导入**：一张卡带走完整身份（记忆 + 风格 + 档案名）。

## 三、安装与升级

前置：已安装 DSH Desktop。

```bash
# npm（推荐）
dsh plugin add lume-dsh-plugin

# GitHub（备选）
dsh plugin add github:cayan0x/Lume#v0.8.0

# 指定版本 / 最新
dsh plugin add lume-dsh-plugin@0.8.0
dsh plugin add lume-dsh-plugin@latest
```

**升级**：再执行一次同样的命令即可（npm 源推荐）。若当初用**本地源码目录**安装（依赖里是 `link:` 指向源码），在源码目录 `git pull && npm install --legacy-peer-deps && npm run build` 后重启 DSH。

**装完必须完全重启 DSH**（含托盘进程）——插件在宿主启动时加载，没有热重载。

## 四、配置

在 DSH 的插件配置里改（键名与 `src/index.ts` 的配置 schema 一致）：

| 配置 | 默认 | 说明 |
|---|---|---|
| `layeredInjection` | `true` | 分层注入：关掉则易变内容回到 system 段（丢前缀缓存，不丢功能） |
| `projectMemory` | `true` | 跨会话项目知识与载具台账 |
| `behaviorTriggers` | `true` | 行为触发器（按轨迹纠偏） |
| `memoryInjection` | `true` | 长期记忆注入 |
| `styleInjection` | `true` | 风格约定注入 |
| `reflectionEnabled` | `true` | 会话结束的反思回环 |
| `extractionProvider` / `extractionModel` | 回落主对话 | 记忆提取专用模型档（可只配其一） |
| `distillProvider` / `distillModel` | 回落主对话 | 人设蒸馏专用模型档（可只配其一） |

## 五、数据与隐私

- 全部数据存在**本机** DSH 存储域里：`<DSH_HOME>/harness/storages/lume_*.json`（人设、记忆、项目知识、反思），会话原文仍由 DSH 自己管理；
- 明文 JSON，**你可以直接查看、备份、删除**；插件自身不做网络请求（除调用你配置的模型档进行提取/蒸馏）；
- 自动沉淀的**敏感内容会被拦截**：带值的密钥、连接串、私钥、加密串一律不入库；
- 想彻底清空：停用插件后删除上述 `lume_*.json` 即可。

## 六、开发

```bash
npm install --legacy-peer-deps   # DSH 生态包与若干 rc 版本存在 peer 冲突，需此开关
npm test                         # 577 个用例
npm run lint                     # 架构规则（分层/ESM/日志/静默失败/类型边界/依赖必须真被使用/文档不许漂）+ 类型检查 + 机制覆盖
npm run build                    # 产出 lib/（不入版本库）
npm run release:check            # 发布门禁（对着产物断言，37 条）
npm run verify:live              # 真机清单（重启后跑：加载行/能力行/RPC/补蒸馏/知识/注入块/客户端产物）
```

工程约定与分层原因见 [ARCHITECTURE.md](ARCHITECTURE.md)；发布流程见 [RELEASING.md](RELEASING.md)；版本变更见 [CHANGELOG.md](CHANGELOG.md)。
