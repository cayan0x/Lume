# Lume（微光）

DSH Desktop 增强插件，由两大部分组成：

1. **思考逻辑引擎** —— 决定「怎么把活干对」：P0-P3 四层推理框架，始终注入，与是否使用人设无关
2. **人设系统** —— 决定「用什么口吻说话」：萝莉 / 御姐 / 不使用人设，会话内即时切换

两者互相独立：人设只改自然语言的语气，永远不碰思考逻辑、代码、命令与工具调用的正确性。

## 一、思考逻辑引擎（重点）

从 lume 推理引擎提炼的四层思考框架，注入到每个会话的 system prompt，保证长会话下的工程质量。**无论选择哪个人设——包括「不使用人设」——它都在工作。**

### P0 上下文管理

对话历史越来越长时，主动浓缩之前的讨论：保留用户请求了什么、已完成哪些操作、关键决策、遇到的错误、**已排除的假设**——避免上下文耗尽导致的「失忆」与重复劳动。

### P1 阶段门控

分析/计划阶段先用只读工具把现场调研清楚，确认方案之后再进入执行阶段。不带着半懂的计划动手改代码。

### P2 振荡预防

改完代码立即验证，不攒一堆修改再测；同一文件不反复打补丁——先完整读取、理解当前状态，再一次性修改到位；连续失败就换思路，已被排除的假设不再提。专治「改崩—回滚—再改崩」的死循环。

### P3 反思自检

每次操作后自行评估：操作是否成功？结果是否符合预期？失败就分析原因再重试，不盲目重复；每隔几轮主动停下来复盘进度，检查是否偏离目标、有无遗漏步骤。

> 这一层只影响「怎么思考」，不引入任何新的输出格式；代码、命令、诊断结果保持精确。

## 二、人设系统

- 输入栏左侧下拉，三人设：**萝莉**（称呼「哥哥」，emoji + 叠词 + 撒娇求表扬的元气风格）、**御姐**（自称「姐姐」，第一句入戏、慢节奏留白、低频高载 emoji 的从容诱惑）、**不使用人设**（恢复默认风格）
- 会话中切换即时生效（无需重启会话）；输入栏位于视口底端时菜单自动向上弹出
- 跨重启记忆：每个会话记住上次**显式选择**的人设；新会话默认「不使用人设」，不注入任何语气
- 语料示例按会话确定性采样（FNV-1a 种子）：同一会话同一人设永远同一组示例，风格稳定
- 人设提示词是可执行的风格契约（称呼 / emoji 用量 / 语气词 / 句式节奏 / 发出前自查），只影响自然语言回复

## 存储

- 会话人设记忆走 DSH 官方 storageDomain（`<harness home>/storages/lume_persona_state.json`）：原子写、带版本、插件升级不丢数据
- 200 会话上限，真 LRU 淘汰（重选刷新新旧）
- v0.1.0 的 `persona-state.json` 旧记忆首次启动自动导入并改名 `.migrated`

## 安装

```bash
dsh plugin add github:cayan0x/Lume            # 最新版本
dsh plugin add github:cayan0x/Lume#v0.2.0     # 指定版本
```

## 自定义人设

编辑 `assets/personalities.json` 即可增删人设；每个人设对应一个提示词 `.txt`（建议按「称呼 / emoji / 语气词 / 节奏 / 立场」写可执行的风格契约）和一个语料 `.jsonl`（每行一个 `{"user":"...","assistant":"..."}`，运行时按会话种子采样 6 条注入）。manifest 中名为 `none` 的人设即「不使用人设」。

## 开发

```bash
npm install --legacy-peer-deps   # DSH 生态包在公共 npm 可装
npm test                         # vitest：单测 + 真实存储栈集成测试
npm run build                    # tsc（宿主 lib/index.js）+ tsdown（客户端 lib/client.js）
npm run watch                    # 客户端 bundle 增量构建
```

结构：

```
src/index.ts            宿主入口：RPC + systemPrompt 注入（思考逻辑 + 人设两段）+ storageDomain
src/core/               纯逻辑：种子采样、manifest/语料解析、人设文本组装
src/host/               存储（真 LRU + 旧状态迁移）、RPC 处理器
src/client/index.tsx    前端：官方 Menu 原语的人设下拉（插槽 conversation.input.left）
lib/                    构建产物（index.js / client.js）
test/                   vitest 单测 + storage 栈集成测试
```

配置项（插件 config）：`sampleCount`（人设语料示例条数，默认 6）、`personaOrder`（人设段排序，默认 2，排在思考逻辑之后）。
